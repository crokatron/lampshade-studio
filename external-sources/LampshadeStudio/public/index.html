 FROM SHADE TO PART

Your CAD workflow

  1. Set the outside width, depth and height in millimetres. Unlock width and depth for an oval shade.
  2. Choose a style and adjust the profile. Changing styles keeps your target envelope.
  3. Export a hollow STEP or BREP for adding mounting and fitting geometry in CAD. The radial wall is an approximation, not constant normal thickness.
  4. Save the design file to preserve the generator parameters. A STEP contains boundary geometry, not a native parametric feature tree.

For vase-mode printing

Choose STL beside the export button and use Solid envelope geometry. Balanced mesh detail is the default; Lite makes smaller files and Fine adds detail. Import STL as millimetres. In the slicer, enable spiral vase mode, one perimeter, no infill, no top layers and no bottom layers for an open sleeve. Set the extrusion width in the slicer. Check the sliced path before printing.

Any base or socket interface you add can change vase-mode compatibility. Use LED lighting and choose your material and clearances for the actual operating temperature.
